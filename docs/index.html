olaf.

License scanner: olaf generate <DIR> scans a project directory, resolves licenses, writes a report to stdout or a file.

One command. Thirteen ecosystems. Zero setup. Fun at parties, serious in CI.

🧭Problems olaf solves

Dependency sprawl is a license-sprawl problem. olaf answers “what licenses ship with my build?” with a single sweep.

🗺️ 13-ecosystem sprawl

One sweep covers npm|nuget|pip|go|cargo|maven|gradle|composer|bundler|swift|cocoapods|vcpkg|conan (pypi alias for pip). Polyglot repo? Still one command.

📋 Audit & SBOM pressure

Emit CycloneDX 1.5 (cyclonedx-json, cyclonedx-xml) or SPDX 2.3 (spdx-json) straight from the same run auditors already trust.

✈️ Air-gap friendly

--offline resolves licenses from the embedded SPDX DB only — zero HTTP. Perfect for locked-down runners and planes.

🚦 CI license gates

--strict fails the build (exit 1) when any license comes back Unknown. Unknowns never slip into a release unnoticed.

💌 Attribution without tears

The md report is a human-readable attribution page: header counts plus a section per package. Paste it into your docs and done.

⚡ Zero-config + always-on cache

generate is the only command and it just works — defaults point at the current directory and print json to stdout. The license cache is internal and always on, so repeat runs stay fast.

📦Install

No .NET install required: each v* tag ships self-contained single-file binaries. Grab one with curl (or gh), make it executable, check the version:

curl -fSL -o /tmp/olaf-dl/olaf-linux-x64 https://github.com/fluxion-dev/olaf/releases/download/v0.1.0-preview.3/olaf-linux-x64
chmod +x /tmp/olaf-dl/olaf-linux-x64
/tmp/olaf-dl/olaf-linux-x64 --version

🚀Usage

Full command shape — generate [PATH] is the only command (PATH defaults to ., the report goes to stdout unless --out is given):

olaf generate <DIR> [--format <fmt>] [--out <file>] [--force] [--strict] [--offline]

Exactly five flags, nothing else:

--format <format>  Output format: json|yaml|xml|md|cyclonedx-json|cyclonedx-xml|spdx-json (default: json)
--out <out>        Output file path (default: stdout; parent directories are created)
--force            Overwrite output file if it exists
--strict           Fail (exit 1) on unknown licenses
--offline          Resolve licenses from the embedded offline DB only (no network; unknown licenses stay Unknown)

Quickstart (exits 0, summary total 3, resolved 2, unknown 1 on the bundled fixture):

olaf generate tests/Olaf.Tests/Fixtures/npm --format json --offline
# {"summary":{"total":3,"resolved":2,"unknown":1},...} (exit 0)

Gate it in CI — the same run exits 1 because one license is Unknown (the report is still written first):

olaf generate tests/Olaf.Tests/Fixtures/npm --format json --offline --strict
# report written, then exit 1 on the Unknown row

Help and version both exit 0:

olaf generate --help
olaf --version
# 0.1.0-preview.3+...

🎨Formats

Seven formats, zero aliases. One sweep, whichever shape your pipeline wants:

FormatOutput
jsonSummary counts plus per-package rows, sorted ecosystem → name → version
yamlSame shape as json, YAML-encoded
xmlSame fields as json, XML-encoded
mdHuman-readable attribution report (header counts + per-package sections)
cyclonedx-jsonCycloneDX 1.5 SBOM
cyclonedx-xmlSame CycloneDX 1.5 data as JSON, XML-encoded
spdx-jsonSPDX 2.3 SBOM

🔢Exit codes

CodeMeaning
0Success — including runs with Unknown licenses (without --strict), empty-directory empty reports, --help/--version
1--strict found Unknown licenses (report is still written first)
2Usage/IO error: path not found, single-file input, unsupported --format, unknown option, --out exists without --force, write failure
